# DELTAS — account-wide self-improvement upgrades

Applying the Weco/AIDE² mechanisms + frontier abstractions (see
`abstractions/registry.md`) to each repo in the SuperInstance account.
Each delta: mechanism → concrete change → owning repo → first build size.

Legend: **[P0]** do first (unblocks others), **[P1]** next, **[P2]** when P0/P1 land.

---

## MicroMoth-quilt (the meta-lab; owns the doctrine)

- **[P0] D1 — Bug-injection self-play loop** (C05+C07). A loop synthesizes bugs
  matched to qcell shape-cards, injects them into `micromoth.py`, runs the
  batteries, records caught/missed plus seeded canaries (`canaries_injected`,
  `canaries_caught` on every receipt). First build: one evening, stdlib only.
  *This is the account's top delta: it manufactures the missing measurement.*
- **[P0] D2 — Held-out gate battery** (C04). Gate shapes generated by an
  independent process (different model family + procedural generator), sealed by
  Casey, opened only at measurement time. The self-play loop never sees it.
  First build: shape generator + seal script + one gate run, a day.
- **[P1] D3 — Lineage fields + bandit allocation** (C03). Every collapse receipt
  gains `loop`, `parent_receipt`, `lineage_id`; a bandit allocates each Loom fire
  budget across loops by lineage survival rate. Instrumentation evening; bandit
  a week with a checkpoint receipt.
- **[P1] D4 — `tools/dream.py`** (C06). Mine ledgers/FINDINGS.md for
  fail→success transitions; emit battery-extension and loop-schedule proposals as
  PRs with receipts. Parser evening; proposer weekend.
- **[P1] D5 — Ladder positions in README** (C12). Every spiral loop states L0
  today; L1 only with a D2 gate receipt. Free, immediate.
- **[P2] D6 — Spiral self-edit loop** (C01). Schedule-as-data + one editor loop
  proposing schedule edits, gated by D2. The account's first reach past the
  frozen-driver ceiling. Only after D1–D3 produce trustworthy numbers.
- **[P2] D7 — Context-compression experiment** (C08). Distill N receipts into
  loop-lore; fixed task suite vs full-history control. Pre-registered pin:
  win iff task success drops ≤1pt and tokens drop ≥5×.

## mothquantum (int8 kernel + harness)

- **[P1] D8 — Freeze the kernel, evolve the harness** (C02). Compression strategy
  selection (fp16/bfp16/exp-i8) becomes a trace-grounded optimization target over
  *harness configs*, with the kernel binary untouched. Gate: fidelity-compression
  frontier must not regress on a held-out circuit slice.
- **[P2] D9 — QD over harness variants** (C11). Lift Lane C's QD-Elites engine to
  search harness configs; characterization dims: fidelity, compression, wall time,
  seed-sensitivity.

## typesafe.ai (typed agent harness)

- **[P1] D10 — TROVE-class route validation** (C09). Traces feed a route-table
  editor; edits validated on a held-out task slice before merge. GEPA's number to
  beat: meaningful gains at 100–500 evals.
- **[P2] D11 — Skill-pack self-audit loop** (C10). Skill packs versioned as code;
  a periodic loop runs pack receipts against a canary task suite and demotes packs
  whose receipts stopped reproducing.

## quantum-audio-honesty (QPAM experiments)

- **[P1] D12 — Held-out honesty gate** (C04). The sim-vs-real envelope experiments
  (Lane B) pre-register a hidden slice of frame/shots combinations; the comparison
  never sees them during development. (Lane B's banked finding — real-decode bias
  outside [0,1] — was found *because* the honest-negative path existed; the gate
  makes it systematic.)
- **[P2] D13 — Lane C integration** (C11). QD diversity search results feed back
  into the honesty envelope as a diversity dimension (does decode bias vary across
  archive cells?).

## pong-quilt (learning demonstration)

- **[P2] D14 — Curriculum co-evolution** (C05). The difficulty-ramp parameters
  (ball acceleration, prediction horizon) become a self-play curriculum: the
  injector maximizes model failure subject to learnability, the solver's
  improvement signal tunes the ramp. Already the fleet's most legible L0→L1 demo
  once a held-out performance gate exists.
